# Flask Todo App

A simple Todo application built with Flask that provides complete CRUD functionality.

## Features

- Add new Todo
- View all Todos
- Update existing Todos
- Delete Todos
- SQLite database
- Bootstrap UI
- Custom CSS styling

## Technologies Used

- Python
- Flask
- Flask-SQLAlchemy
- SQLite
- HTML
- CSS
- Bootstrap
- Jinja2
